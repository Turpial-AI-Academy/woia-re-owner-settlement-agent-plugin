# Owner settlement

Use only owner-settlement.import/read/extract-link/source-version.accept/reconcile/delivery-package. Load [contract](references/contract.md) for acceptance/discrepancy/delivery; use [helper](scripts/settlement.mjs) and [source schema](assets/source.schema.json).

1. Resolve trusted current organization, actor, Task, exact settlement/action grant, policy digest/version and Source Authority Map. Model assertions are not credentials.
2. Import an exact external version with original verified USABLE DocumentVersion. The external administration system remains formal calculator; no vendor/adapter is advertised as qualified.
3. Link attributable extraction as Evidence, not accepted Fact. Reconcile without rewriting external source or Ledger; preserve discrepancies and UNKNOWN.
4. Finance accepts the exact version only after extraction, reconciliation and current policy-governed/approval-required authority. Recheck holds, freshness, revocations and revisions. Approval binds source/payload digest; independence applies only where configured.
5. Finance prepares exact version/beneficiary/content-checksum package. Customer Service reads only approved package and dispatches through Communications with separate recipient/purpose/channel authority. Delivery is not payout.

Never calculate/issue settlement, pay, post money, send to people, pick a backend or duplicate Domain Contracts. Report blockers and immutable evidence refs. Helpers are local deterministic contracts, not credentials or remote adapters. Hosts must resolve authentic context, validate canonical references and persist state/history/result atomically with revision compare-and-swap. Operator E2E and production qualification remain separate.
